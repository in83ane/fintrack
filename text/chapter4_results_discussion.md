# บทที่ 4
# ผลการวิจัยและการอภิปรายผล

การดำเนินโครงงานพัฒนาระบบ FinTrack ซึ่งเป็นเว็บแอปพลิเคชันจัดการพอร์ตโฟลิโอและการเงินส่วนบุคคล มีวัตถุประสงค์เพื่อพัฒนาระบบที่ช่วยให้ผู้ใช้สามารถติดตามการลงทุน จัดการกระแสเงินสด (Cashflow) ตั้งงบประมาณผ่านระบบ Money Buckets และมีระบบช่วยให้คำแนะนำผ่านดัชนีชี้วัดทางคณิตศาสตร์และปัญญาประดิษฐ์ (AI) โดยในบทนี้จะนำเสนอผลการพัฒนาระบบ ผลการทดสอบระบบ และการอภิปรายผลการวิจัย ดังต่อไปนี้

---

## 4.1 ผลการพัฒนาระบบ (Results of System Development)

จากการออกแบบและพัฒนาระบบด้วย Next.js, React, Tailwind CSS และฐานข้อมูล Supabase (PostgreSQL) ทำให้ได้เว็บแอปพลิเคชัน FinTrack ที่สามารถทำงานได้จริงตามวัตถุประสงค์ที่ตั้งไว้ โดยมีผลการพัฒนาฟังก์ชันหลักดังนี้

### 4.1.1 ผลการพัฒนาระบบจัดการพอร์ตโฟลิโอและกระแสเงินสด
ระบบสามารถบันทึกและแสดงภาพรวมของสินทรัพย์ทั้งหมด (Total Net Worth) รวมถึงคำนวณกำไร/ขาดทุน (Profit/Loss) ได้แบบ Real-time โดยรองรับสินทรัพย์หลากหลายประเภท (หุ้น, คริปโทเคอร์เรนซี) นอกจากนี้ ผู้ใช้ยังสามารถบันทึกรายรับ-รายจ่ายผ่านระบบ Ledger (Cashflow) และจัดสรรเงินเข้าสู่เป้าหมายต่าง ๆ ผ่านฟีเจอร์ Money Buckets ได้ตามที่กำหนด ข้อมูลทั้งหมดถูกนำมาแสดงผลในหน้า Dashboard ผ่าน Widget แบบ Drag-and-drop ที่ผู้ใช้สามารถปรับแต่งได้เอง

### 4.1.2 ผลการพัฒนาระบบวิเคราะห์สัญญาณซื้อขายด้วยคณิตศาสตร์ (Trade Signal & Market Scanner)
ระบบสามารถดึงข้อมูลราคาแบบ Real-time จาก Yahoo Finance API มาคำนวณด้วย **หลักการทางคณิตศาสตร์และสถิติ (Rule-based Algorithm)** โดยใช้ Technical Indicators ถึง 12 ตัว (เช่น RSI, MACD, EMA, Stochastic, ADX, VWAP) รวมถึงสูตรการคำนวณ Smart Money Concepts (SMC) เพื่อประมวลผลออกมาเป็นคะแนนความมั่นใจ (Confidence Score 0-100%) และคำแนะนำพื้นฐาน (STRONG BUY, BUY, WATCH, NO SIGNAL) พร้อมทั้งใช้สูตรคณิตศาสตร์คำนวณจุดเข้าซื้อ (Entry) และจุดตัดขาดทุน (Stop Loss) จากค่าความผันผวน (ATR) นอกจากนี้ยังมีระบบ Market Scanner ที่ช่วยคำนวณตามสูตรดังกล่าวเพื่อสแกนหาหุ้นในตลาด SET และ US

### 4.1.3 ผลการพัฒนาระบบที่ปรึกษาทางการเงิน AI (AI Financial Advisor)
ระบบมีการรวมปัญญาประดิษฐ์ (AI) แยกต่างหากในรูปแบบของ Chatbot โดยเชื่อมต่อกับ Google Gemini API เพื่อทำหน้าที่เป็นผู้ช่วยส่วนตัว AI สามารถอ่านข้อความภาษาธรรมชาติ (Natural Language) เช่น "วันนี้กินข้าวไป 150 บาท" แล้วแปลงเป็นข้อมูลบันทึกลงฐานข้อมูลรายจ่ายให้อัตโนมัติ รวมถึงสามารถวิเคราะห์ข้อมูลพอร์ตโฟลิโอเบื้องต้นเพื่อตอบคำถามผู้ใช้ได้

### 4.1.4 ผลการพัฒนาระบบรองรับหลายสกุลเงิน (Multi-Currency Support)
ระบบรองรับสกุลเงินหลัก 4 สกุล ได้แก่ USD, THB, JPY และ EUR โดยระบบจะทำการดึงอัตราแลกเปลี่ยนปัจจุบันมาคำนวณและแปลงค่าทรัพย์สินทั้งหมดให้อยู่ในสกุลเงินฐานที่ผู้ใช้เลือก ทำให้ผู้ใช้ที่มีการลงทุนข้ามประเทศสามารถเห็นมูลค่าทรัพย์สินที่แท้จริงของตนเองได้

## 4.2 ผลการทดสอบระบบ (Results of System Testing)

หลังจากพัฒนาระบบเสร็จสิ้น ได้ทำการทดสอบการทำงานของระบบ (System Testing) เพื่อประเมินประสิทธิภาพและความถูกต้อง โดยมีผลการทดสอบดังนี้

### 4.2.1 ผลการทดสอบการทำงาน (Functional Testing)
จากการทดสอบการรับส่งข้อมูล การบันทึกธุรกรรม การคำนวณผลตอบแทน และการคำนวณ Technical Indicators พบว่าระบบสามารถทำงานได้ถูกต้องตามสูตรคณิตศาสตร์ที่ตั้งไว้ ระบบ Authentication ผ่าน Google OAuth สามารถล็อกอินและสร้าง Session ได้ตามมาตรฐาน การดึงข้อมูล API ภายนอกมีระบบ Fallback ทำให้ระบบยังคงทำงานต่อไปได้เมื่อบาง API ไม่ตอบสนอง

### 4.2.2 ผลการทดสอบความปลอดภัย (Security Testing)
จากการทดสอบนโยบายความปลอดภัยระดับแถว (Row Level Security - RLS) ในฐานข้อมูล Supabase พบว่าผู้ใช้ไม่สามารถเข้าถึงข้อมูลของบัญชีอื่นได้ การทำงานของ Middleware สามารถบล็อก Request ที่น่าสงสัย ป้องกันการโจมตีแบบ CSRF และทำ Rate Limiting ได้ตามมาตรฐาน OWASP

### 4.2.3 ผลการทดสอบการแสดงผล (Responsive Design Testing)
ผลการทดสอบการแสดงผลบนอุปกรณ์ที่แตกต่างกัน (Desktop, Tablet, Mobile) พบว่า Layout ของระบบสามารถปรับเปลี่ยนขนาดและจัดเรียงองค์ประกอบ (Responsive) ได้ เมนู Sidebar สามารถยุบเป็น Bottom Navigation บนสมาร์ทโฟนได้ ทำให้รองรับการใช้งานในหลายขนาดหน้าจอ

## 4.3 การอภิปรายผล (Discussion)

จากการพัฒนาระบบและการทดสอบ สามารถนำมาอภิปรายผลข้อสรุปปัญหาในการวิจัย การแปลความหมายของข้อมูล และการเปรียบเทียบกับระบบหรือการวิจัยที่มีมาก่อนได้ดังนี้

### 4.3.1 การอภิปรายข้อสรุปปัญหาในการวิจัย
ปัญหาหลักที่ผู้ลงทุนรายย่อยและบุคคลทั่วไปพบเจอ คือความยุ่งยากในการใช้แอปพลิเคชันหลายตัวแยกกัน (เช่น แอปจดรายรับ-รายจ่ายแยกกับแอปติดตามพอร์ตหุ้น) การพัฒนาระบบ FinTrack เป็นแนวทางในการแก้ปัญหาเหล่านี้ โดยการรวมศูนย์ข้อมูลทางการเงิน (All-in-One Dashboard) ทำให้ผู้ใช้เห็นภาพรวมของความมั่งคั่ง (Net Worth) ที่แท้จริง และระบบ Money Buckets ช่วยสร้างวินัยในการจัดการเงิน

### 4.3.2 การแปลความหมายของข้อมูลและข้อจำกัดของระบบ Trade Signal
ในส่วนของระบบ Trade Signal ที่ประมวลผลออกมาเป็น **Confidence Score** นั้น ถือเป็นการนำข้อมูลราคา (Price Action) มาแปลความหมายผ่าน **หลักการทางคณิตศาสตร์และสูตรทางสถิติ (Mathematical Models)** เท่านั้น เช่น การคำนวณค่าเฉลี่ยเคลื่อนที่ (EMA) หรือโมเมนตัม (RSI) ซึ่งแม้จะช่วยให้ผู้ใช้มีเกณฑ์ตัดสินใจที่เป็นระบบและลดอคติ (Bias) จากอารมณ์ได้ แต่**ระบบนี้ยังมีข้อจำกัดอย่างมากเมื่อเทียบกับการใช้ AI วิเคราะห์เชิงลึก** 

เนื่องจากโมเดลคณิตศาสตร์เหล่านี้ไม่สามารถรับรู้ปัจจัยเชิงคุณภาพ (Qualitative Factors) เช่น ข่าวสารเศรษฐกิจมหภาค นโยบายการเงิน หรือแนวโน้มอุตสาหกรรมได้ ระบบเป็นเพียงการคำนวณย้อนหลัง (Lagging Indicators) เท่านั้น การให้ความหมายของคำว่า "BUY" หรือ "STRONG BUY" จึงเป็นเพียงผลลัพธ์จากสมการทางคณิตศาสตร์ที่ตรงตามเงื่อนไขที่กำหนดไว้ (Rule-based) ไม่ใช่การประเมินทิศทางตลาดด้วยสติปัญญาแบบ AI ที่สามารถพิจารณาบริบทรอบด้านได้ 

### 4.3.3 ผลการวิจัยเทียบกับการวิจัยหรือแอปพลิเคชันที่มีมาก่อน
เมื่อนำระบบ FinTrack ไปเปรียบเทียบกับแอปพลิเคชันจัดการการเงินและการลงทุนที่มีอยู่ในตลาด (เช่น Money Lover, Investing.com, หรือ TradingView) พบว่า:

1. **ด้านความครอบคลุม (Comprehensiveness):** แอปพลิเคชันส่วนใหญ่มักมุ่งเน้นไปที่ด้านใดด้านหนึ่ง เช่น แอพทำบัญชีก็จะไม่สามารถดึงราคาหุ้น Real-time ได้ ส่วนแอปดูหุ้นก็จะไม่สามารถบันทึกค่ากาแฟได้ FinTrack สร้างความแตกต่างด้วยการรวม Cashflow และ Portfolio Management ไว้ด้วยกัน
2. **ด้านการวิเคราะห์ข้อมูลทางเทคนิค:** แพลตฟอร์มอย่าง TradingView มีเครื่องมือ Indicator ที่ครอบคลุม แต่ผู้ใช้จำเป็นต้องมีความรู้และตั้งค่าด้วยตนเอง ระบบ FinTrack ช่วยรวมสูตรคณิตศาสตร์เหล่านั้นมาประมวลผลเป็นคะแนนสรุป (Score) ทำให้ผู้ใช้เริ่มต้นได้ง่ายขึ้น แม้จะยังไม่เทียบเท่าการใช้นักวิเคราะห์ที่เป็นคนหรือโมเดล AI ขั้นสูงก็ตาม
3. **ด้านการใช้ AI ช่วยเหลือ:** แม้ระบบวิเคราะห์หุ้นจะใช้เพียงคณิตศาสตร์ แต่ FinTrack ได้เพิ่มระบบ **AI Chatbot (Gemini)** เข้ามาช่วยในด้านการปฏิสัมพันธ์กับผู้ใช้ (User Interaction) เช่น การแยกแยะข้อความเพื่อบันทึกรายจ่ายอัตโนมัติ ซึ่งเป็นฟีเจอร์ที่ทำให้แอปมีความยืดหยุ่นและใช้งานง่ายกว่าการกรอกฟอร์มแบบดั้งเดิม

สรุปได้ว่า ระบบ FinTrack เป็นแพลตฟอร์มทางการเงินที่ผสานการจัดการพอร์ตโฟลิโอและกระแสเงินสดเข้าด้วยกัน โดยมีเครื่องมือช่วยประมวลผลทางสถิติและคณิตศาสตร์เป็นผู้ช่วยด้านข้อมูล และมี AI เป็นผู้ช่วยในการใช้งาน ตอบโจทย์การใช้งานทางการเงินในชีวิตประจำวันตามวัตถุประสงค์ที่ตั้งไว้
