# FinTrack

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Individual investors managing their own portfolios. Confirmed by the user on 2026-10-25. Thai and English are supported.

## Product Purpose

Track personal investments, transactions, cash flow, budgets and investment goals in one application. Help investors understand their current position and accurately record activity.

## Operating Context

Next.js App Router application with multiple portfolios, USD/THB display conversion, investment analytics, trade planning, cash-management buckets and spreadsheet import. Desktop, laptop and mobile web are required.

## Capabilities and Constraints

Preserve all existing routes, financial calculations, API calls, data logic, features and bilingual behavior. This project is a visual and interaction redesign only. Existing uncommitted work must be preserved. Do not fabricate performance, benchmarks, prices or financial history when data is absent.

## Brand Commitments

FinTrack should feel calm, precise and trustworthy. The user explicitly requests a private-bank/modern-fintech direction, dark-first with a separately designed light theme, and one indigo brand accent across all workspaces, with page identity limited to faint background tints and navigation indicators; gain/loss colors remain fixed. No casino styling, neon glows, emoji icons or decorative charts.

## Product Principles

- Financial accuracy and clear currency context precede decoration.
- Each view has an obvious information hierarchy and primary action.
- Missing, stale, loading and error data remain distinguishable.
- Motion preserves continuity without obscuring financial meaning.
- Existing features and Thai/English workflows remain available.

## Accessibility & Inclusion

WCAG AA target; keyboard navigation, visible focus, semantic tables, reduced-motion alternatives, text labels of at least 12px and body text of at least 14px. Financial changes use signs or arrows as well as color. Sensitive amounts can be hidden through a privacy control.

## Evidence on Hand

The user's detailed redesign brief and the existing implementation. No new benchmark data, contact service or additional financial endpoints are authorized by this redesign.
